개인정보처리방침

앱 이름: Hoon's뷰어 · 패키지: com.scorebook.app
시행일: 2026년 11월 10일

본 방침은 악보 뷰어 앱 ‘Hoon's뷰어’(이하 “본 앱”)의 개인정보 처리에 관한 내용을 설명합니다.

1. 수집하는 개인정보

본 앱은 어떠한 개인정보도 수집하지 않습니다. 회원가입이나 로그인 절차가 없으며, 개발자는 사용자의 악보·필기·녹음·설정에 접근할 수 없습니다.

2. 데이터의 저장

사용자가 불러온 악보 파일(PDF·사진), 필기, 북마크, 세트리스트, 연습 기록, 녹음, 설정 등 모든 데이터는 사용자의 기기 내부에만 저장되며 외부 서버로 전송되지 않습니다. 본 앱에는 악보가 포함되어 있지 않으며, 사용자가 직접 가지고 있는 파일만 엽니다.

3. 네트워크 및 제3자 제공

본 앱은 인터넷 권한을 사용하지 않습니다. 광고와 분석 도구가 없으며, 데이터를 제3자에게 제공하지 않습니다. 얼굴 인식과 글자 인식에는 Google ML Kit 을 사용하지만, 인식 모델이 앱에 들어 있어 모든 처리가 기기 안에서 이루어집니다.

4. 권한

권한사용 목적데이터 처리
카메라 (선택) ‘얼굴 제스처로 넘기기’ 기능을 켰을 때 전면 카메라로 고개 방향을 인식해 페이지를 넘깁니다. 영상은 기기 안에서 실시간으로만 분석하며, 저장하거나 전송하지 않습니다.
마이크 (선택) 연습 도구에서 사용자가 ‘녹음’을 눌렀을 때 연습을 녹음합니다. 녹음 중에는 알림이 표시됩니다. 녹음 파일은 기기 내부에만 저장되며, 사용자가 앱에서 직접 삭제할 수 있습니다.

두 권한 모두 해당 기능을 사용할 때만 요청하며, 허용하지 않아도 악보 보기와 필기 등 나머지 기능은 그대로 쓸 수 있습니다. 사진·파일은 사용자가 시스템 파일 선택 화면에서 직접 고른 것만 읽습니다.

5. 백업 파일

설정의 ‘백업 파일 만들기’는 사용자가 지정한 위치에 zip 파일을 저장합니다. 이 파일의 보관과 공유는 전적으로 사용자가 결정하며, 본 앱이 어디로도 올리지 않습니다.

6. 데이터의 삭제

기기에서 본 앱을 삭제하면 저장된 모든 데이터가 함께 삭제됩니다. 또한 시스템 설정의 ‘저장공간 → 데이터 삭제’로도 초기화할 수 있습니다.

7. 아동의 개인정보

본 앱은 아동을 포함한 어떤 사용자로부터도 개인정보를 수집하지 않습니다.

8. 방침의 변경

본 방침이 변경될 경우 본 페이지를 통해 고지합니다.
