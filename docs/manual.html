1설치하기

Play 스토어가 아닌 설치 파일(APK)로 배포하는 테스트 버전입니다.

  1. 받은 HoonsViewer_V1.1.apk 파일을 태블릿(또는 휴대폰)으로 옮깁니다 (카카오톡, 메일, 구글 드라이브, USB 등).
  2. 태블릿의 내 파일(또는 카카오톡 파일함)에서 APK 를 누릅니다.
  3. "출처를 알 수 없는 앱" 안내가 나오면 설정 → 해당 앱(내 파일·카카오톡 등)의 이 출처 허용을 켜고 돌아옵니다.
  4. 설치를 누릅니다. Play 프로텍트가 "알 수 없는 앱" 경고를 띄우면 세부정보 → 무시하고 설치를 고르세요.
  5. 앱 목록에 Hoon's뷰어가 생기면 완료입니다.
주의 서버가 없어 모든 악보와 필기는 그 기기에만 있습니다. 앱을 지우면 데이터도 함께 지워지니, 지우거나 기기를 바꾸기 전에 설정 → 백업 파일 만들기를 해 두세요.
업데이트 새 버전 APK 를 받으면 지우지 말고 그대로 설치하면 됩니다. 악보와 필기는 유지됩니다. 현재 버전은 설정 맨 아래 "앱 버전"에서 확인할 수 있어요.
V1.1 바뀐 점 휴대폰처럼 좁은 화면 지원 — 상단 버튼 정리(⋮ 더보기로 이동), 곡 자동 나누기 화면에서 이름 칸과 미리보기가 겹치던 문제, 페이지 편집 화면이 비어 보이던 문제, 사진 악보 제목 칸, 필기 레이어 이름 표시, 필기 도구 줄바꿈 수정. 목록 패널 위에서 대화상자를 닫으면 패널까지 닫히던 문제 수정.

2화면 구성

왼쪽(세로 화면에서는 아래쪽) 메뉴로 네 화면을 오갑니다.

메뉴하는 일
악보불러온 악보 목록. 검색·정렬·즐겨찾기·태그로 찾고, 눌러서 엽니다.
셋리스트공연·레슨 순서대로 악보를 묶어 두고 차례로 엽니다.

설정보기 방식, 페이지 넘기기, 펜, 얼굴 제스처, 백업.

3악보 불러오기·정리

불러오기

  • 오른쪽 아래 + 악보 추가 → PDF 파일 불러오기. 여러 파일을 한 번에 고를 수 있고, 같은 파일은 중복으로 들어가지 않습니다.
  • 사진으로 악보 만들기: 종이 악보를 찍은 사진 여러 장을 한 권의 악보로 만듭니다. (12장)
  • 다른 앱에서 PDF 나 사진을 공유 → Hoon's뷰어 또는 열기 → Hoon's뷰어 해도 바로 들어옵니다.

찾기·정리

  • 검색창: 제목·작곡가·태그로 찾습니다. 초성 검색도 됩니다 (예: ㅇㅁ → 아멘).
  • 오른쪽 위 정렬 버튼: 최근에 연 순 / 제목순 / 작곡가순 / 추가한 순.
  • 악보 카드의 ⋮: 정보 편집(제목·작곡가·장르·조성·태그), 페이지 편집, 즐겨찾기, 셋리스트에 추가, 삭제.
  • 카드를 길게 누르면 여러 개 선택 모드가 됩니다. 선택한 악보를 합치기(한 권으로), 셋리스트에 추가, 한꺼번에 삭제할 수 있어요.

두 페이지가로 화면에서 책처럼 두 장을 나란히.

세로 스크롤페이지를 위아래로 이어서 스크롤. 자동 스크롤과 함께 쓰기 좋습니다.
색상기본 / 야간(반전) / 세피아
여백 자동 자르기악보 주변 흰 여백을 잘라 음표를 더 크게 보여 줍니다.
  • 두 손가락으로 벌려서 확대, 확대한 상태에서 끌어서 이동. 확대한 부분은 선명하게 다시 그려집니다.
  • 아래쪽 슬라이더를 끌면 원하는 페이지로 빠르게 이동합니다.
  • 마지막으로 보던 페이지를 기억해서 다음에 열면 그 페이지부터 보여 줍니다.

6펜으로 필기하기

펜(S펜 등)을 화면에 대기만 하면 자동으로 필기 모드가 켜집니다. 손가락은 계속 페이지 넘기기·확대에 쓰이므로 펜으로 쓰다가 손가락으로 바로 넘길 수 있어요. 필기는 한 획마다 즉시 저장되어 앱을 꺼도 그대로 남습니다.

필기 도구

도구설명
펜색상·굵기 선택. 압력에 따라 굵기가 자연스럽게 변합니다.
형광펜반투명으로 겹쳐 칠하기
지우개획 지우개: 닿은 획을 통째로 / 영역 지우개: 네모 크기만큼 문질러 부분만 지우기 (크기 조절). S펜 옆 버튼을 누른 채 문질러도 지우개가 됩니다.
올가미둘러서 선택 → 끌어서 이동, 휴지통으로 삭제
도형직선 ─, 네모 □, 동그라미 ○, 화살표 → 등
텍스트원하는 곳을 눌러 글자 입력 (예: 여기서 숨쉬기). 다시 누르면 수정
음악 기호셈여림(pp~ff), 아티큘레이션, 쉼표·음표, 숨표, 페르마타, 지시어 160여 개(rit., a tempo, cresc. …)를 도장처럼 찍기. 크기는 슬라이더 또는 숫자를 직접 입력
  • 실행 취소 / 다시 실행: 필기 막대의 ↶ ↷ 버튼
  • 레이어: "선생님 지시", "내 연습 메모", "공연용" 처럼 나눠 두고 필요할 때만 켜고 끌 수 있습니다. 새 필기는 선택한 레이어에 들어갑니다.
  • 손가락으로 쓰기: 펜이 없으면 필기 막대에서 켜면 손가락으로도 쓸 수 있습니다 (이때는 손가락으로 넘기기 대신 필기).
  • 손바닥 무시: 펜이 화면 가까이 있으면 손바닥 터치를 무시합니다 (설정에서 끄고 켜기).
  • 필기 막대의 ✕ 로 필기 모드를 닫습니다.

8도돌이표·D.S. 링크

D.S., Coda, 도돌이표처럼 다른 페이지로 점프해야 하는 곳에 링크를 걸어 두면, 연주 중 그 위치를 탭해 바로 이동합니다.

  1. 위쪽 🔗 링크 버튼을 눌러 링크 편집 모드로 들어갑니다.
  2. 점프할 표시(예: D.S. 글자) 위를 손가락으로 드래그해 네모를 그립니다.
  3. 이동할 페이지를 썸네일에서 고르면 링크가 생깁니다.
  4. 🔗 버튼을 다시 눌러 편집 모드를 끕니다.
  • 연주 중 링크 네모를 탭하면 그 페이지로 이동하고, 위쪽에 N쪽으로 돌아가기가 뜹니다. 필요 없으면 옆의 ✕ 로 닫으세요.
  • 링크 목록: ▦ 페이지 → 링크 탭에서 모든 링크를 한눈에 봅니다.
    줄 누르기 = 링크가 있는 페이지로 / → = 도착 페이지로 / ✎ = 이름(예: "D.S. → 세뇨")과 도착 페이지 수정 / 🗑 = 삭제
  • 📖 보기 → 링크 표시를 끄면 악보 위 링크 네모를 숨길 수 있습니다.

9곡 자동 나누기·곡 바로가기

여러 곡이 한 PDF 에 붙어 있는 악보집이라면, 곡마다 바로가기를 자동으로 만들 수 있습니다.

  1. ⋮ 더보기 → 곡 자동 나누기 (또는 위쪽 곡 버튼 → 자동으로 곡 나누기)
  2. 앱이 모든 페이지를 살펴봅니다. 160쪽 정도면 30초~1분 걸립니다.
    • 마지막 마디가 끝세로줄(얇은 선 + 굵은 선)로 끝나는 페이지를 찾고
    • 다음 페이지 맨 위에 크게 쓴 제목이 있는지 확인해 곡 시작으로 판단합니다.
    • 제목 글자를 읽어(OCR) 곡 이름을 붙이고, 악보집 앞에 목차가 있으면 목차로 오타를 고칩니다.
  3. 찾은 곡 목록이 나옵니다. 이름이 틀렸으면 고치고, 표지처럼 곡이 아닌 것은 체크를 빼세요.
  4. N곡으로 나누기를 누르면 완료.
  • 위쪽 곡 3/19 버튼을 누르면 곡 목록이 열리고, 곡을 누르면 바로 그 곡으로 이동합니다. 곡이 많으면 검색(초성 가능)도 됩니다.
  • 제목 옆에 지금 보고 있는 곡 이름이 표시됩니다.
  • 곡은 북마크로 저장됩니다. ▦ 페이지 → 곡·북마크 탭에서 이름을 바꾸거나 지울 수 있어요.
팁 모든 분석은 기기 안에서만 이루어집니다. 제목이 없거나 아주 작은 악보집, 손글씨·흐린 스캔은 놓치거나 이름을 잘못 읽을 수 있으니 확인 화면에서 한 번 훑어봐 주세요. 직접 만들려면 곡 첫 페이지에서 🔖+ 북마크를 누르면 됩니다.

10셋리스트

  • 왼쪽 메뉴 셋리스트 → 새 셋리스트 (예: 10월 정기연주회) → 곡 추가
  • 끌어서 순서를 바꾸고, 곡마다 시작 위치(북마크)를 정할 수 있습니다. 악보집 안의 한 곡만 넣을 때 유용해요.
  • 셋리스트로 열면 마지막 페이지에서 다음으로 넘길 때 다음 곡이 바로 열립니다.
  • 악보 목록에서 여러 악보를 길게 눌러 선택한 뒤 셋리스트에 한꺼번에 넣을 수도 있습니다.

11페이지 편집

⋮ 더보기 → 페이지 편집 (또는 악보 목록 카드의 ⋮). 원본 파일은 건드리지 않고, 필기는 페이지를 따라 함께 움직입니다.

  • 길게 눌러 끌어서 순서 변경
  • 페이지를 선택한 뒤 회전(왼쪽/오른쪽), 자르기(여백 자동 감지 가능, 선택한 모든 페이지에 적용), 삭제
  • 빈 오선지 넣기: 메모나 추가 악보를 쓸 빈 페이지
  • 새 악보로 나누기: 선택한 페이지만으로 새 악보 만들기

12사진으로 악보 만들기

  1. 악보 목록 → + 악보 추가 → 사진으로 악보 만들기
  2. 사진 선택(갤러리) 또는 파일에서 여러 장을 고릅니다. 고른 순서대로 페이지가 됩니다.
  3. 길게 눌러 끌어서 순서를 바꾸고, 회전 버튼으로 방향을 맞춥니다.
  4. 제목을 입력하고 악보 만들기(앱 안에서 보기) 또는 PDF로 저장(파일로 저장·공유).

17자주 묻는 질문

펜을 댔는데 필기가 안 돼요

펜 대신 손가락으로 터치되는 경우입니다. 정전식 일반 터치펜은 손가락으로 인식되니 필기 막대에서 손가락으로 쓰기를 켜 주세요.

필기 중 손바닥 때문에 페이지가 넘어가요

설정 → 펜 → 손바닥 무시가 켜져 있는지 확인하세요.

블루투스 페달이 안 먹어요

태블릿 블루투스 설정에서 페달이 "연결됨"인지 확인하고, 페달 모드를 키보드(PageUp/PageDown 또는 방향키)로 맞춰 주세요.

곡 자동 나누기 결과가 이상해요

확인 화면에서 틀린 이름은 고치고, 잘못 잡힌 곡은 체크를 빼면 됩니다. 놓친 곡은 그 페이지에서 북마크로 직접 추가하세요. 어떤 악보집에서 틀렸는지 알려 주시면 개선에 큰 도움이 됩니다.

앱을 지웠다 다시 깔면 필기가 남아 있나요?

아니요. 데이터가 기기 안에만 있어 함께 지워집니다. 꼭 먼저 백업해 주세요. 업데이트(덮어 설치)는 데이터가 유지됩니다.

인터넷이 필요한가요?

전혀 필요 없습니다. 악보 분석, 제목 읽기, 얼굴 인식 모두 기기 안에서 처리됩니다.
