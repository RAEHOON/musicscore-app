```
Hoon's뷰어 - 악보 뷰어·필기
```

```
내 PDF·사진 악보를 넘겨 보고 펜으로 바로 필기하는 오프라인 악보 뷰어. 페달·고개 넘김, 메트로놈까지.
```

**자세한 설명** (4000자 이내)

```
Hoon's뷰어는 가지고 있는 악보 파일을 태블릿에서 편하게 보고 연습하기 위한 악보 뷰어입니다.
서버도, 회원가입도, 광고도 없습니다. 인터넷 권한조차 쓰지 않아서 악보와 필기는 기기 밖으로 나가지 않습니다.

※ 이 앱에는 악보가 들어 있지 않습니다. 직접 가지고 있는 PDF나 사진을 불러와서 사용합니다.

■ 악보 불러오기·정리
· PDF 여러 개를 한 번에 불러오기, 다른 앱에서 "열기/공유"로 바로 보내기
· 종이 악보를 찍은 사진 여러 장을 하나의 악보로 만들기
· 한글 초성 검색, 태그·즐겨찾기, 정렬
· 여러 악보를 하나로 합치기, 선택한 페이지만 새 악보로 나누기

■ 보기
· 한 페이지 / 가로 두 페이지 / 반 페이지 넘김 / 세로 스크롤
· 확대해도 선명한 고해상도 렌더링, 야간·세피아 모드, 여백 자동 자르기
· 마지막으로 보던 페이지 기억

■ 손을 쓰지 않고 넘기기
· 블루투스 페달, 볼륨 버튼
· 자동 넘김 / 자동 스크롤
· 얼굴 제스처: 화면을 본 뒤 고개를 돌리면 페이지가 넘어갑니다 (영상은 기기 안에서만 처리)

■ 펜으로 필기
· 펜을 대면 바로 필기 모드, 손바닥 무시
· 펜·형광펜·지우개·올가미·도형·텍스트
· 음악 기호 스탬프와 지시어 160여 개
· 레이어, 실행 취소/다시 실행
· 필기를 포함해 PDF로 저장 (다른 PDF 앱에서도 그대로 보입니다)

■ 연주를 위한 기능
· 도돌이표·D.S.·Coda 점프 링크와 돌아가기
· 악보집에서 곡 시작 페이지를 자동으로 찾아 곡 바로가기 만들기
· 셋리스트: 공연 순서대로 묶고, 마지막 페이지에서 다음 곡 자동 열기
· 공연 모드

■ 연습 도구
· 메트로놈 (탭 템포)
· 음정 확인용 피아노 건반
· 연습 녹음, 음원 첨부 + 속도 조절 + A-B 구간 반복
· 연습 시간 자동 기록과 통계

■ 백업
· 악보·필기·녹음·설정을 zip 파일 하나로 백업하고 복원

권한 안내
· 카메라(선택): 얼굴 제스처로 페이지를 넘길 때만 사용
· 마이크(선택): 연습을 녹음할 때만 사용
두 권한 모두 허용하지 않아도 나머지 기능은 그대로 쓸 수 있습니다.
```

## Console 설문 답안

**앱 액세스 권한**: 모든 기능을 제한 없이 사용할 수 있음 (로그인 없음)

**광고**: 광고 없음

**콘텐츠 등급**: 카테고리 "유틸리티, 생산성, 커뮤니케이션 또는 기타" → 폭력·성적 콘텐츠·도박·사용자 간 소통·위치 공유 모두 "아니요"

**타겟층**: 만 13세 이상 (아동 대상으로 설정하면 추가 심사가 붙는다)

**데이터 보안**
- 사용자 데이터를 수집하거나 공유하나요? → **아니요**
- 근거: 병합된 매니페스트에 INTERNET 권한이 없다(ML Kit 이 끌고 오는 것을 `tools:node="remove"` 로 제거). 카메라 영상은 기기에서만 분석하고 저장하지 않으며, 녹음은 기기에만 저장된다. "수집"은 기기 밖으로 전송하는 것을 뜻하므로 해당 없음.

**포그라운드 서비스 (마이크 유형)**
- 용도 설명:
  ```
  사용자가 연습 도구에서 '녹음' 버튼을 눌러 악기 연습을 녹음하는 동안에만 실행됩니다.
  녹음 중 다른 앱(메트로놈, 반주 앱 등)으로 잠시 전환해도 녹음이 끊기지 않도록 하기 위한 것이며,
  '녹음 중' 알림이 계속 표시되고 사용자가 '정지'를 누르면 즉시 종료됩니다.
  ```
- 시연 영상: 악보 열기 → ♪ 연습 도구 → 녹음·음원 → 녹음 → 홈 버튼 → 알림 확인 → 앱 복귀 → 정지 → 재생 (30초 내외 화면 녹화)

**권한 사용 사유 (요청받을 때)**
- 카메라: 전면 카메라로 고개 방향을 인식해 손을 쓰지 않고 악보를 넘기는 선택 기능. 영상은 저장·전송하지 않음.
- 마이크: 사용자가 직접 시작한 연습 녹음.

## 출시 빌드

```
./gradlew :app:bundleRelease
```

결과물: `app/build/outputs/bundle/release/app-release.aab`
`keystore.properties` 가 없으면 디버그 키로 서명되어 Play 에 올릴 수 없다. 릴리스 키스토어가 있는 PC에서 빌드할 것.
